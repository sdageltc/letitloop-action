letitloop-action

Proof-carrying verification gate for GitHub Actions. Prevents AI coding agent signature drift, decorator stripping, and scope boundary leakage on Pull Requests.

🛍️ Marketplace Action 💻 GitHub Repo ⚙️ Engine Core 🏆 Durability Bench

🚀 1-Minute GitHub Actions Setup

Add .github/workflows/letitloop-verify.yml to your repository:

name: Verify AI Pull Request

on:
  pull_request:
    branches: [ main ]

permissions:
  contents: read
  pull-requests: write

jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Run LetItLoop Verification Gate
        uses: sdageltc/letitloop-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          strict-ast: 'true'
          test-command: 'pytest -q'

🛡️ Core Verification Guarantees

📐 AST Signature Invariance

Verifies function signatures, parameter names, type annotations, and default values are preserved across edits.

🔒 Scope Fence Enforcement

Fails the PR if an AI agent touches files outside declared task output boundaries or modifies protected configurations.

📜 Cryptographic Proof Receipts

Hashes test output, execution duration, and AST checks into a SHA-256 receipt posted directly to PR comments.
