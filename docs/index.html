Workflow Configuration

Drop-In CI Durability Gate

Enforce zero-regression AST invariants and proof receipts on every incoming Pull Request.

# .github/workflows/letitloop-gate.yml
name: LetItLoop Proof Verification Gate
on:
  pull_request:
    branches: [ "main" ]

jobs:
  verify-durability-proof:
    name: Verify AST Invariants & HMAC Proof Receipts
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Pull Request Branch
        uses: actions/checkout@v4

      - name: Execute LetItLoop Gate
        uses: sdageltc/letitloop-action@v2
        with:
          strict_ast: true
          require_proof_receipt: true
          fail_on_undeclared_outputs: true
Core Protections

CI Security & Conformance Features

Autonomous defense against broken AST nodes, runaway file modifications, and unverified AI code.

FEATURE 01

Strict AST Syntax Gate

Runs Python AST parser across every modified file in the PR diff. Rejects syntax errors, unbalanced brackets, and broken tokens before test runs.

FEATURE 02

HMAC Receipt Verification

Validates the cryptographic seal of .bench_wal/proof_receipt.json to prove that tests and benchmarks were physically executed.

FEATURE 03

Undeclared Output Fencing

Fails closed if the agent writes files outside its declared output scope, preventing unauthorized modifications to workflow files or configs.

FEATURE 04

Scorecard Compliance

Fully compatible with OpenSSF Scorecard and EU Cyber Resilience Act (CRA) machine-verifiable verification mandates.

FEATURE 05

PR Benchmark Diffing

Automatically benchmarks recovery latency on the PR branch and posts an ASCII comparative summary directly to the pull request.

FEATURE 06

Zero Token Leakage

Runs in isolated CI environments without requiring access to host secrets, external databases, or third-party webhooks.
