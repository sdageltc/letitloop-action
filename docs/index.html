letitloop-action

Zero-config GitHub Action running AST invariant validation, scope fencing, and deterministic verification on AI-generated Pull Requests.

🚀 1-Minute GitHub Actions Quickstart

Add this single workflow file to any repository to guard against AI agent hallucinations, parameter drift, and decorator stripping:

# .github/workflows/letitloop-verify.yml
name: Verify AI Pull Request
on:
  pull_request:
    branches: [main, master]

permissions:
  contents: read
  pull-requests: write

jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - name: Run LetItLoop Verification Gate
        uses: sdageltc/letitloop-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          strict-ast: 'true'
          test-command: 'pytest -q'

✨ 3 Core Guarantees

🧬 1. AST Invariance

Mathematically verifies that function names, argument types, defaults, and return annotations are preserved during refactoring.

🚧 2. Scope Fencing

Fails closed if an AI agent touches unauthorized directories, modifies security configurations, or deletes production tests.

🔏 3. Proof Receipts

Signs execution telemetry with HMAC-SHA256 non-repudiation receipts, preventing tampered test results from entering main.
