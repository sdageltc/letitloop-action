# Integrating letitloop-action with AI Workflows

This guide explains how to configure `letitloop-action` to verify Pull Requests generated by AI coding agents and automated dependency bots.

---

## 1. Automated Dependency Bots (Renovate & Dependabot)

When Dependabot or Renovate upgrades Python packages, major version bumps can introduce breaking signature changes without breaking simple import tests.

Add this workflow at `.github/workflows/verify-dependency-prs.yml`:

```yaml
name: Verify Dependency PR

on:
  pull_request_target:
    branches: [ main ]

permissions:
  contents: read
  pull-requests: write

jobs:
  verify-deps:
    # Run on PRs opened by dependabot or renovate
    if: github.actor == 'dependabot[bot]' || github.actor == 'renovate[bot]'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          ref: ${{ github.event.pull_request.head.sha }}

      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'

      - uses: sdageltc/letitloop-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          strict-ast: 'true'
          test-command: 'pytest tests/ -q'
```

## 2. Cursor & AI IDE Agents

When developers use Cursor, Windsurf, or Copilot Workspace to submit PRs, configure scope boundary leasing to prevent undeclared file modifications:

```yaml
name: Verify AI Scope Boundary

on:
  pull_request:
    types: [ opened, synchronize ]

permissions:
  contents: read
  pull-requests: write

jobs:
  scope-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: sdageltc/letitloop-action@v1
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          scope-fence: 'src/**,tests/**'
          test-command: 'npm test'
```

---

## 3. Claude Code & CLI Agent Automation

For headless agent loops creating PRs via GitHub CLI (`gh pr create`), `letitloop-action` serves as the automated acceptance gate before merge:

- Proves unit tests ran and exited with code `0`.
- Generates a machine-readable SHA-256 evidence bundle for compliance auditing.
- Emits structured pass/fail status checks that block GitHub branch merges if AST invariants fail.
